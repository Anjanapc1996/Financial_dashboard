# Financial_dashboard|Power BI

📌 Project Overview

This project presents an interactive Financial Performance Dashboard developed using Microsoft Power BI. The dashboard helps analyze actual financial performance against target values and monitor performance through variance analysis and Year-to-Date (YTD) metrics.

It also provides sales person-wise and team-wise performance analysis to support better business decisions.

🎯 Project Objectives

-> Monitor actual financial performance against targets.

-> Identify performance gaps using variance analysis.

-> Track financial performance over time.

-> Analyze individual sales person performance.

-> Compare performance across different teams.

-> Monitor Year-to-Date (YTD) performance.

📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

-> Total Actual Value – Displays the actual financial value.

-> Total Target Value – Displays the target financial value.

-> Variance – Shows the difference between actual and target values.

-> Variance % – Represents the variance as a percentage.

-> Total YTD – Displays the Year-to-Date actual value.

.

📈 Dashboard Features

-> Actual vs Target performance comparison.

-> KPI trend analysis using calendar dates.

-> Sales person-wise performance analysis.

-> Team-wise performance comparison.

-> Variance and Variance % analysis.

-> Interactive Sales Person and Team slicers.

-> Sales person performance table with variance trend.

🔍 Key Insights

-> Actual vs Target comparison helps evaluate overall financial performance.

-> Variance analysis highlights the gap between actual and target values.

-> Variance % helps compare performance gaps across sales people and teams.

-> Sales person-wise analysis helps identify individual performance differences.

-> Team filters allow users to focus on specific team performance.

-> YTD and date-based trends support time-based performance monitoring.

Note: These are analytical insights supported by the dashboard features. Actual top performers and numerical findings depend on the selected data and filter context.
